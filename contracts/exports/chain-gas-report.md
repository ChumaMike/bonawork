# Bona Chain gas report

Generated by `pnpm chain:gas` (`contracts/test/chain/stress.test.ts`). Do not edit by hand.

Measured on Hardhat's local network with the compiler settings used for Fuji
(solc 0.8.28, optimizer 200 runs, EVM `cancun`). Gas **units** carry over to Fuji; the
AVAX cost is `units x gas price`, and the gas price is not something a local run can know.

### What the run did

- 4,200 random steps: 2,523 transactions the model said must succeed (all did) and 1,677 attempts it said must be refused (all were, with the predicted error).
- 121 role re-assignments of two floating accounts.
- 189 of 200 reports ended Verified = 189 RepairVerified events.
- 155 releases authorised = 155 ReleaseAuthorised events, each one eligible by the model and by an audit of the events alone.
- Every institution uses the same report and work order ids; each ended in the state its own model predicted.
